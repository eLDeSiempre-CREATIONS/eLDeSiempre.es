eLDeSiempre — Flipper Zero BadUSB Suite
Suite de herramientas educativas para Flipper Zero, enfocada en:
Auditoría autorizada
Pruebas de concepto
Aprendizaje de DuckyScript
Estructura
payload/
├── ascii/            ASCII art (inofensivo)
├── pranks-win/       Pranks Windows (inofensivo)
├── pranks-mac/       Pranks macOS (inofensivo)
├── goodusb-mac/      Utilidades macOS
├── recon-local-mac/  Recon local (solo lectura)
└── chromeos/         ChromeOS inofensivo
Uso
Copia la carpeta `payload/` a la SD del Flipper (`BadUSB/`).
Ejecuta desde el Flipper.
Solo en equipos propios o con autorización escrita.
Aviso
Este repositorio NO contiene grabbers, backdoors, stealers ni destructivos.
Los grabbers con webhook están en la SD del Flipper, nunca en GitHub.
